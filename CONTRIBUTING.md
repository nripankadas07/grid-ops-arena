# Contributing

1. Open an issue describing the behavior and evidence for the change.
2. Keep runtime code on the Python 3.9 standard library.
3. Mark example data as synthetic and add a fixed seed for stochastic generation.
4. Add or update `unittest` coverage and run `make test`.
5. Document schema changes and update `CHANGELOG.md`.

Small, reviewable pull requests are preferred. Never include production credentials, private grid data, or claims that synthetic examples are current facts.
